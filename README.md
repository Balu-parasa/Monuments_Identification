## 📌 Overview

**Monument Identification** is an AI-powered mobile application that recognizes Indian monuments from user-provided images using Deep Learning and Computer Vision techniques.

The application predicts the monument from an uploaded image and presents relevant historical and cultural information, making heritage exploration more interactive and accessible for students, travellers, and history enthusiasts.

The project consists of two independent modules:

- 🤖 AI Model for monument recognition
- 📱 React Native mobile application for user interaction

# 🚀 Getting Started

### Clone Repository

```bash
git clone https://github.com/Balu-parasa/Monuments_Identification.git
```

### Navigate to Mobile Application

```bash
cd monument-app
```

### Install Dependencies

```bash
npm install
```

### Start Development Server

```bash
npx expo start
```
